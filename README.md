# PortfolioHUB - André Magalhães

Este repositório foi criado como parte da atividade acadêmica de Criação de Repositório com Versionamento.

## Objetivo

Organizar projetos acadêmicos e pessoais em um repositório versionado, utilizando Git, GitHub, documentação em Markdown e publicação com GitHub Pages.

## Estrutura do Repositório

- `projetos-academicos/`: projetos desenvolvidos durante a faculdade.
- `projetos-pessoais/`: projetos desenvolvidos para estudo e prática.
- `documentacao/`: arquivos de planejamento e apresentação.
- `assets/`: imagens e recursos utilizados na página.
- `index.html`: página principal do portfólio.
